# Homework 3 — Java Basics

A collection of simple Java programs written as part of the COM 103 Programming course.

All source files are located in the src/ folder.

## Programs

| File | Description |
|------|-------------|
| ATM.java | Simple ATM simulator. PIN verification (3 attempts), check balance, deposit and withdraw money. |
| FizzBuzz.java | Classic FizzBuzz problem. |
| Guess.java | Number guessing game. |
| Even.java | Working with even numbers. |
| Odd.java | Working with odd numbers. |
| Pin.java | PIN-related program. |
| Number.java | Basic number operations. |
| Statistics.java | Calculating simple statistics. |
| For.java | Example of using for loop. |
| Before.java | Example of using for loop. |
| Infinite.java | Example of an infinite loop. |

## How to Run

1. Open any .java file in your IDE (IntelliJ IDEA, Eclipse, VS Code, etc.).
2. Run the main method.

Or via terminal:
`bash
javac src/ATM.java
java -cp src ATM
(Replace ATM with the name of the program you want to run.)

Topics Covered:
Java basics

Loops (while, for)
